
# Machine Learning Laboratory Experiments

This repository presents the machine learning experiments and coursework completed during Semester 6. It organizes assignments, datasets, implementations, and reports in a structured format.

---

## Repository Structure

```

ML-lab-main/
├── A1/                  # Data Analysis and Visualization
├── A2/                  # Naive Bayes and K-Nearest Neighbors
├── A3/                  # Regression Techniques
├── A4/                  # Logistic Regression and SVM
├── req.txt              # Project dependencies
├── README.md            # Project documentation
└── .gitignore           # Git ignore configuration

```

Each assignment directory contains the required notebooks, datasets, plots, and reports.

---

## Assignments and Topics

The following table summarizes the experiments conducted in this laboratory:

| Assignment | Focus Area | Methods Implemented | Datasets Used |
|------------|------------|--------------------|---------------|
| **A1** | Exploratory Data Analysis | Data analysis and visualization techniques | Iris, Loan, Diabetes, Spam, MNIST |
| **A2** | Classification | Naive Bayes, K-Nearest Neighbors | Spambase |
| **A3** | Regression Modeling | Linear, Ridge, Lasso, Elastic Net | Loan Amount Prediction |
| **A4** | Classification | Logistic Regression, Support Vector Machine | Spambase |

## Datasets

The experiments use the following datasets:

- **Iris Dataset** – Multi-class classification  
- **Spambase Dataset** – Email spam detection  
- **Loan Prediction Dataset** – Loan amount estimation  
- **Diabetes Dataset** – Binary classification  
- **MNIST Dataset** – Handwritten digit recognition  

---

## Execution Instructions

Follow these steps to run the experiments:

1. Install the required dependencies:

```bash
pip install -r req.txt
````

2. Navigate to the desired assignment directory:

```bash
cd A1   # or A2, A3, A4
```

3. Launch Jupyter Notebook:

```bash
jupyter notebook notebooks/
```

---

## Assignment Directory Contents

Each assignment folder includes:

* `notebooks/` – Jupyter notebooks containing implementations
* `dataset/` – Datasets used for the experiments
* `plots/png/` – High-resolution PNG visualizations (600 DPI)
* `plots/eps/` – EPS format plots for LaTeX reports
* `report.pdf` – Final compiled report
* `README.md` – Assignment-specific documentation
